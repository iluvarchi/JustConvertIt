Enter the folder
`cd JustConvertIt/`

Create the virtual environment:
`python -m venv .venv`

If needed, install this using Ubuntu WSL:
`sudo apt update && sudo apt install -y sed`

Inside the folder, activate the environment:
`source venv/Scripts/activate`

Alternatively, run the virtual environment directly:
`source /d/JustConvertIt/.venv/Scripts/activate`

Run the application in the terminal afterwards:
`python main.py`

Deactivate by simply typing: 
`deactivate`
